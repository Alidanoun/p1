# Al-Markazia Backend Infrastructure 🚀

بنية خلفية متطورة ومحصنة للتعامل مع الطلبات الحساسة، إدارة الفروع الإقليمية، التسعير الديناميكي، وبروتوكولات الأمان المتقدمة.

## 🌟 الميزات الهندسية الأساسية
1. **نظام ساعات السعادة المعزول زمنياً (Timezone-Aware Happy Hour):**
   - يدعم الفروع الإقليمية بمناطق زمنية متباينة (`Asia/Dubai`، `Africa/Cairo`، `Asia/Riyadh`، إلخ) باستقلالية تامة.
   - يتكامل مع الـ Cron Jobs والـ Sockets بشكل ديناميكي معزول ضد أخطاء التوقيت الصيفي (DST).
2. **منع حالات السباق (Idempotency Race Condition Mitigation):**
   - بنية قفل هجينة (Redis + Database) مع التراجع الأسي العشوائي (Exponential Backoff with Jitter).
3. **التدقيق المالي الصارم (Financial Audit Trails):**
   - تتبع كامل للأحداث عبر كائنات غير قابلة للتغيير وتدقيق سببي للمعاملات.
4. **التقييد الموزع للطلبات (Distributed Rate Limiting):**
   - حماية ذرية فائقة الأداء عبر **Lua Scripts** تمنع تجاوز موازن الحمل مع دعم التقييد الهرمي لطلبات الفروع.
   - يدعم ترويسات المراقبة المتقدمة:
     - `X-RateLimit-Limit`: الحد الأقصى المسموح.
     - `X-RateLimit-Remaining`: الرصيد المتبقي للطلبات.
     - `X-RateLimit-Reset`: التوقيت الزمني لإعادة الضبط بالثواني.
5. **حل تضارب المزامنة غير المتصلة (Offline Concurrency Resolution):**
   - بروتوكول **التحكم المتفائل بالتزامن (OCC)** يمنع التحديثات المفقودة عبر الترويسات (`X-Entity-Version`، `X-Client-Timestamp`) مع تشفير محلي مزدوج وتصحيح تفاعلي للنزاعات.
6. **الدقة المصرفية لحسابات الولاء (Loyalty Banking Precision):**
   - حماية مطلقة ضد انحراف الفاصلة العائمة باستخدام **Decimal.js** وتوحيد التقريب (`ROUND_HALF_UP`) مع مراقبة استباقية للأرصدة وتدقيق صارم للحركات.
